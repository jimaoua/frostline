# Frostline

Isometric arcade survival in the snow. Vite + React + TanStack Router, with a
framework-free canvas engine.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build
```

`src/routeTree.gen.ts` is committed so the app runs immediately; the router
plugin regenerates it whenever files in `src/routes` change.

## Structure

```
src/
  main.tsx                 router bootstrap
  routeTree.gen.ts         generated by @tanstack/router-plugin
  routes/__root.tsx        root layout (Outlet)
  routes/index.tsx         "/" → GameView
  ui/                      React HUD only (never touches the canvas per frame)
    GameView.tsx           mounts Game, owns the canvas
    Hud.tsx                staged panels: objective / resources / defense
    useHud.ts              useSyncExternalStore over Game snapshots
  game/
    Game.ts                loop host: update → render → HUD snapshot (~8 Hz)
    hud.ts                 the only data React can see
    core/                  constants, types, iso math, rng
    world/                 layout (quadrants, gates, spots), base/stockade, world factory
    systems/               motion, player, interact, workers, defense, routing, build, effects
    progression/phases.ts  the 4 phases, one objective at a time
    input/input.ts         WASD/arrows + floating touch joystick
    render/                renderer, ground, stockade, nature, structures, characters, floor pads, fx
```

## Design rules baked into the code

**Movement and facing.** Every walker (player, lumberjacks, miner, hauler, wolves)
shares `systems/motion.ts`. Facing is stored as a screen-space angle derived from
the actual velocity, smoothed, with flip hysteresis. The renderer blends front,
three-quarter and profile views from that angle, shows the back when moving
up-screen, and leans into motion. When standing still, characters turn toward
whatever they are working on. Footprints (boots or paws) are dropped
left/right of the stride and painted onto the ground plane, then fade out.

**Progression.** `progression/phases.ts` is the single source of truth. Each
step has `enter` (what it reveals), `progress` and `done`. Pads, rocks,
counters and the defense UI only appear when their step or phase begins.

| Phase | Missions (each one introduces something new) |
| --- | --- |
| 1 First Light | Chop 6 logs, light the campfire |
| 2 Survivors | Rescue a freezing survivor (becomes your first lumberjack), catch 3 fish, build the grill from woodpile logs, cook & serve your first guests, buy the Fisher's Shack ($60: fisher + cook automate the kitchen) |
| 3 Settlement | Bonfire upgrade ($80: more survivors, warmer), Lumberjack Hut ($120), East Yard ($300) |
| 4 Trade & Stone | Trading Post (20 logs), Quarry Camp ($250), mine 8 stone |
| 5 Hold the Line | Watchtower ($400), first wolf pack, iron ore expedition, North Yard ($600), second tower ($600) |
| 6 Frontier | Workshop ($500), Sharp Axes, Shelter, Traps, Gatehouse, endless days |

Measured with a no-cheat bot (`window.game.step` driving only the joystick):
first automation at ~1:10, Phase 4 at ~3:40, Phase 5 at ~5:50, Phase 6 at ~9:30,
endless at ~15:30. Expect a human to take roughly 1.5–2× as long.

Purchase pads show a large upright price badge (always readable), the price
printed on the floor, a progress ring and fill, a gold pulsing state when you
can afford it, and a grey locked **NEXT** preview of the following unlock. A
yellow chevron / edge arrow guides you to the current objective.

See `docs/rendering-direction.md` for the planned move to real-time 3D.

### The physical economy

Fish at the ice hole → drop the catch at the grill (it visibly cooks) → carry
meals to the serving hatch → survivors queue outside the wall, take a meal and
pay → bills bounce onto the cash pad → step on it and the cash stacks on your
back → walk onto a `$` pad to spend it. Every transfer is an item flying in an
arc, never just a number changing.

### Living settlement and events

Survivors arrive by road, queue, cheer when served, shiver in the cold, leave or
(once a Shelter exists) settle in and wander by the fire, huddle in blizzards
and panic during raids. From Phase 5 an event director runs **blizzards**
(stay in the fire's warm ring), **trader caravans** (sell at double, hire a
survivor) and **signal flares** (rescue a survivor guarded by a bear). Wolves and
bears patrol outside the walls and chase you when you wander out. A bear swipe
knocks items out of your arms, and if you're knocked out you drop your whole load.

**Base and stockade.** The base is the union of unlocked quadrants. Walls are
recomputed from that union, so an expansion removes the shared wall
automatically. The player collides with walls and NPCs route through gates.

**Assets and proportions.** Sprites have a logical size and a ground anchor,
are cached at zoom × DPR, and are always drawn with one uniform scale.
`render/sprites.ts → loadImageSprite()` takes only a target height and derives
the width from the image's native aspect ratio, so bitmap art can replace the
vector placeholders without stretching.

## Rendering

Shaded, lit-from-upper-left vector art (no external images), cached as sprites
at zoom × DPR. A half-resolution light map darkens the scene at night and
during storms, with lights punched through for the fire, windows, lanterns,
torches and the scout flare. Juice: arcing item flyers with spin, squash on
receive, popups, hit-stop, screen shake, shockwave rings, confetti, and
construction scaffolds that reveal buildings from the ground up.

## Debugging

In dev, `window.game` exposes `debugWorld` and `step(dt, dir)` for scripted
playtests.
